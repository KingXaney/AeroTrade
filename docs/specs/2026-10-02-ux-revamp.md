# UX revamp — home, a slim rail, theme-shaped boxes, processed news, a Learn section

**Date:** 2026-10-02
**Status:** Implemented — `64eb527` (groundwork), `d174285` (themes), `1dfa22f` (shell), `9ba8e3f` (Home), `75f474a` (landing), `7f4b62b` (news), `88030ea` (Learn), `e39e263` (pages). Supersedes in part [Themes + dashboard widgets](2026-08-24-themes-and-dashboard-widgets.md) (the dashboard is no longer `/`; the shell's sidebar is gone), [Personal news feed](2026-09-17-news-feed.md) (the page's layout, and `/history` no longer shows the feed) and [Learn](2026-09-27-learn.md) (`/learn` is a hub).

## Context

Four complaints from the owner, and what was measured behind each:

- **No front door.** A visitor with no session was redirected from every path to the sign-in form. After sign-in, `/` was a nine-widget grid with no greeting and nothing to do next.
- **Clutter.** 29 controls on every page before its own content: eight header tabs, the same eight again in a sidebar of thirteen links, two summary cards, Trade Now, Logout twice, a floating chat button. `/brain`, `/portfolio` and `/settings` stacked 8–11 equal boxes.
- **Boxes that ignored the theme.** Three of the five visual styles shared a panel fill; every caption was uppercase mono in all of them, the light Paper preset included; the header, sidebar, menus, dialogs, drawer and chat window ignored the style axis.
- **News as a wall.** `/news` was 24 identical cards in fetch order: no summary, grouping or ranking.

Decisions taken with the owner: a public landing page *and* a signed-in Home; a slim icon rail; each style shapes its boxes, labels and chrome (boxes inside boxes stay); motion, interactive boxes and content that adapts — not live-updating data; an AI briefing plus grouped stories; a beginner course, with everything educational under one Learn section.

## What shipped

**Themes.** Per-style tokens for type roles (`--label-*`, `--heading-*`, `--control-*`), inner cards (`--card-*`), chrome (`--chrome-*`) and motion (`--motion-*`), read by `MicroLabel`, `SectionHeading`, `ActionButton`, `Badge`, `RowCard`, `.news-item`, the header, the rail and every floating surface. Minimal, liquid-glass and soft write sentence-case words; futuristic keeps the terminal captions; brutalist is bold uppercase with an inverted heading chip. A style block sets only style tokens — a palette block outranks it.

**Shell.** `lib/shell/navigation.ts` is sections: eight icons on a 64px rail, a section's other pages as links above the page, Friends and Settings in the avatar menu. The rail never widens — a name is a tooltip, the two old sidebar cards are portaled hover cards, and what they showed all the time is a dot on the icon. 29 always-on controls became 12.

**Home and landing.** `/` is Home for a session (accounts under one total, the next first-week step and then the session's, topics, the briefing, the next lesson) and the landing page without one (`proxy.ts` rewrites exactly `/` to `/welcome`). The widget grid is `/dashboard`. Landing copy is under the no-advice list and quotes only the app's own constants.

**News.** One model call a day writes a global `MarketBriefing` from the brain's most important tagged articles; the model cites by number and never supplies a link. `/news` is the briefing, the followed topics with their briefs, tagged articles naming a held or watched symbol, then six top stories with the rest behind a disclosure. One outlet rule covers every section.

**Learn.** `/learn` is a hub (Course, Today, Glossary, Strategies). The course is four modules of four lessons; a lesson frames, quotes the glossary, links to the real screen and asks one question. Progress is derived from rows first and a stamp-once id second, shown as a count.

**Pages.** `/brain` and `/settings` show one view at a time; `/portfolio` leads with the account's numbers; `/history` is the Activity page; a stock page mounts one reference embed at a time.

## Deliberately not done

- `/portfolio` as tabs: its four QA suites read every panel off one page load. It was reordered instead.
- Fuzzy cross-outlet clustering on the live feed: token similarity merges "rises" with "falls". The briefing's stories are the model's grouping, validated against the articles it was shown.
- Live-updating prices, a cap on the strategy trade log, ticker hover previews, a return path across sign-in.

## Verification

`npm run check`, `npm run build:check` and `npm run qa` (14 suites) at every phase, on Windows (the harness and two source-scanning tests were made to run there first), with `visual-sweep` under each of the five styles and the Paper palette.
